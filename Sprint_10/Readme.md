🌍 Global Fundraising Campaign Performance Dashboard

//📌 Project Overview

This project presents an interactive Global Fundraising Campaign Performance Dashboard developed using Google Looker Studio. The dashboard analyzes fundraising campaign performance across different countries, regions, categories, and fundraising platforms.
The primary goal of this project is to help organizations understand fundraising effectiveness, donor engagement, marketing impact, and campaign success rates through data-driven insights.


//🎯 Objectives
Analyze the impact of marketing spend on fundraising success.
Measure the effectiveness of various fundraising platforms.
Track campaign achievement rates against fundraising goals.
Identify top-performing organizations, categories, and regions.
Monitor donor contributions and campaign status distribution.
